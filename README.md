# Ultimate NFC Curator

Ultimate NFC Curator is a project about giving classic Commodore hardware a modern, physical, and joyful way to launch software.

At its heart, this is a curator and launcher for Commodore 64, Commodore 128, and Ultimate-II+/Ultimate 64 style setups. It lets a collection of games, demos, utilities, music, disks, cartridges, and other retro software be organized on a modern machine, then launched on real or Ultimate hardware with the tap of an NFC card.

The goal is not to replace the charm of the old machines. The goal is to remove just enough friction that the old machines get used more often.

## Why this exists

Vintage computers are wonderful, but large software collections can become awkward fast. Disk images pile up. File names get messy. Some programs need special loading steps. Some work perfectly, some almost work, and some deserve to be quietly forgotten in a digital shoebox.

Ultimate NFC Curator is meant to help with that.

Instead of hunting through folders, remembering launch commands, or keeping notes scattered across files, this project builds a curated library around the software. Once something is tested and accepted, it can be tied to a simple NFC card.

Tap the card, and the selected program launches.

That is the magic trick.

## What it demonstrates

This project demonstrates how older hardware can be given new life without stripping away what makes it interesting.

It combines:

- Classic Commodore software and workflows.
- Ultimate-II+/Ultimate style storage and launching.
- A modern PC-side curator database.
- NFC cards as physical launch tokens.
- Search, testing, approval, and cleanup tools for large collections.

The result is a bridge between eras: real retro hardware on one side, modern convenience on the other.

## The NFC idea

The NFC cards are intentionally simple. A card does not need to contain a complicated script or a full configuration. It can point to a curated item, while the computer-side database decides how that item should be launched.

That means the collection can improve over time without constantly rewriting every card.

A card can become a physical shortcut for a game, a demo, a utility, a music file, or anything else worth launching.

## Curating instead of hoarding

This project is built around curation, not just accumulation.

A large retro archive is easy to collect but hard to enjoy. Ultimate NFC Curator is meant to help answer practical questions:

- Does this image work?
- Is this version worth keeping?
- Does it need special instructions?
- Is there a better version?
- Should it become part of the permanent library?
- Should it get an NFC card?

The software supports the idea of testing candidates, promoting the good ones, and discarding the rest. It is less about having everything and more about making the best things easy to use.

## Assembly64 integration

The project includes work toward Assembly64 search and intake. Assembly64 candidates can be searched, downloaded locally, tested, and then either promoted into the curated library or discarded.

Downloaded items are treated as candidates first. They are not immediately treated as permanent library items. This keeps the main collection cleaner and makes room for review, testing, and better organization.

## A physical library for digital software

One of the most enjoyable parts of the project is turning digital software back into something physical.

An NFC card can represent a favorite game. A printed label can make it feel like part of a real collection. A box of cards can become a browsable library for software that originally lived on disks, tapes, cartridges, and mysterious archive folders with names only a goblin could love.

That physical interaction is part of the point.

## Project status

This is an active work-in-progress project. Some parts are experimental, some are rough, and some are being refactored as the workflow becomes clearer.

Current focus areas include:

- Improving the curator interface.
- Organizing large software collections.
- Testing and promoting Assembly64 candidates.
- Supporting more launch types cleanly.
- Making the codebase easier to maintain.
- Reducing the amount of manual fiddling required to enjoy the old machines.

## Who this is for

This project is for people who love old Commodore hardware, enjoy modern-retro hybrids, and want a smoother way to actually use their collections.

If you like the idea of tapping a card and watching a real or Ultimate-powered Commodore setup come alive, this is the kind of strange little contraption you may appreciate.

## In short

Ultimate NFC Curator is a way to take classic Commodore software, organize it thoughtfully, and launch it from physical NFC cards.

It is part preservation tool, part launcher, part collection manager, and part excuse to make old hardware feel freshly alive again.
